# CRM & Engagement

Relationships drive renewals and referrals. The **CRM Dashboard** makes sure you never drop the ball on a touchpoint, and turns "I should message my clients" into a one-click action.

It's organized into three tabs.

## 1. Birthdays

Everyone in your book with a birthday this month, in one list. Each has an editable WhatsApp message template with a `{name}` placeholder that fills in automatically, and there's a **Send All Birthday Greetings** button that opens WhatsApp for each client in turn (with a short delay between each so it doesn't fire them all at once).

## 2. Festive

Broadcast a festive greeting to a chosen group of clients, filtered by race (Chinese, Malay, Indian, or Others — set on each [client's record](./database)) so the message you send actually fits the occasion. You can attach an e-card image to the message, but note it isn't sent automatically with the WhatsApp message — you'll need to paste it in yourself once the chat opens.

## 3. Reviews

Every client whose policy review is coming due, based on the review frequency you set on their record. This is your worklist for "who do I need to book a review with this month."

---

Like Birthdays, both the Festive and Reviews tabs use editable WhatsApp templates with the same `{name}` placeholder, so you can tune the wording once and reuse it every month.

> **Skandage Tip:** Review frequency is set per client, not globally — a HNW client you see quarterly and a term-only client you see annually can both be tracked accurately from the same Reviews tab.
